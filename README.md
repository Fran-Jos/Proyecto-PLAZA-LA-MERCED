# Local Control POS

Sistema de Punto de Venta (POS) para locales comerciales, desarrollado con Java (Spring Boot) y Vue 3.

## Estructura del Proyecto
- `backend/`: API REST desarrollada con Spring Boot 3.
- `frontend/`: Aplicación SPA desarrollada con Vue 3 y PrimeVue.

## Requisitos
- Java 17+
- Node.js 22+
- PostgreSQL
